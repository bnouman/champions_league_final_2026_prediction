Data sources
============

Primary dataset
---------------

The compiled match dataset `data/ucl_matches_2021_22_to_2025_26.csv` was assembled from JSON match feeds provided by FixtureDownload (an aggregator that mirrors competition fixtures/results). The `source_url` values included in the CSV reference the following season feeds:

- https://fixturedownload.com/feed/json/champions-league-2021
- https://fixturedownload.com/feed/json/champions-league-2022
- https://fixturedownload.com/feed/json/champions-league-2023
- https://fixturedownload.com/feed/json/champions-league-2024
- https://fixturedownload.com/feed/json/champions-league-2025

These feeds in turn mirror official match data published by UEFA. Users who require authoritative records or licensing details should consult UEFA directly.
